# SENDAS 1.3 — GitHub Pages

Repositorio: https://github.com/estebancaballeroai/sendas-cronicas-de-galilea

Sitio: https://estebancaballeroai.github.io/sendas-cronicas-de-galilea/

- Mantener `index.html`, `game.js`, `historical-context.js`, `styles.css`, `premium.css`, `sw.js`, `manifest.webmanifest`, iconos y `assets/` en la raíz.
- GitHub Pages está configurado para `main` / raíz. La publicación se realiza tras subir la actualización validada.
- Preservar un commit o rama de respaldo de la 1.1 y no romper la estructura de guardado.
- Para comprobar la publicación: abrir el sitio en móvil, entrar en la primera escena, abrir el cuaderno histórico, completar una misión y recargar la página.
- La PWA usa `sendas-vida-galilea-v1.3.0`. Si un dispositivo conserva archivos antiguos, cerrar la aplicación y volver a abrirla conectado antes de intentar jugar sin conexión.
