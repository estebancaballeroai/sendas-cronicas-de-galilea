# SENDAS 2.1 — QA de integración

Criterios antes de publicar: validación estática, JavaScript syntax, tests de migración, simulación determinista, Playwright Chromium y despliegue GitHub Pages. Los resultados de CI se comprueban en GitHub Actions antes de fusionar. Una prueba fallida bloquea la fusión.

Pruebas nuevas: un único contenedor de diálogo, documentos migrados marcados como visitados, opciones de testigos persistentes, petición aplazada de Irit reabrible, persistencia después de recarga, cierre por Escape con restauración del foco y capturas de móvil en artefactos CI.

La rama estable 2.0 se conserva como `backup/pre-2.1.0-unificacion`.
