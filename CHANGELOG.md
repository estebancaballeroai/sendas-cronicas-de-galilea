# SENDAS — Historial de versiones

## 1.3.1 — Estabilidad móvil

- Visor de fotografías con aumento de 1× a 3×.
- Acceso táctil a acciones y reducción de movimiento cuando el sistema lo solicita.
- Copia de seguridad automática de la primera partida compatible cargada y posibilidad de restaurarla.
- Recuperación de imagen de portada si falla una fotografía de escena.
- Estrategia de caché de red preferente para HTML, JavaScript y CSS, con copia local disponible sin conexión.
- Conserva el Capítulo I, sus tres misiones, diálogos y la clave de guardado.
